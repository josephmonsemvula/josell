ASSISTANCE

❓ Guide d'utilisation

🚀

Comment démarrer ?

Cliquez sur Commencer ou ouvrez le Calculateur.

📦

Créer une catégorie

Dans Groupes & Articles, créez vos catégories de produits.

💵

Enregistrer les ventes

Indiquez combien vous avez vendu dans chaque catégorie.

🛒

Enregistrer les achats

Indiquez combien vous avez dépensé pour acheter vos marchandises.

💸

Enregistrer les dépenses

Ajoutez les dépenses comme transport, salaire, loyer, électricité, etc.

📈

Calcul du bénéfice

Bénéfice net = Ventes − Achats − Dépenses

📊

Rapport hebdomadaire

JOSSELL rassemble les journées de la semaine pour calculer automatiquement le résultat.

📆

Rapport mensuel

Toutes les journées du mois sont regroupées pour produire le résultat mensuel.

💾

Conservation des données

Vos données restent enregistrées dans le navigateur grâce au stockage local.

🔐

Vos informations

JOSSELL utilise vos données uniquement pour effectuer les calculs et produire les rapports.
