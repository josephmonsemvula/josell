📲 Installer JOSSELL

Vous pouvez utiliser JOSSELL comme une application sur votre ordinateur ou votre téléphone.

  1. Ouvrez JOSSELL avec Google Chrome ou Microsoft Edge.
  2. Cliquez sur Installer l'application .
  3. Si le navigateur affiche Installer , confirmez.
  4. Si aucune fenêtre d'installation n'apparaît, ouvrez le menu ⋮ du navigateur.
  5. Choisissez Installer JOSSELL ou Ajouter à l'écran d'accueil .

ASSISTANCE

❓ Guide d'utilisation

🚀

Comment démarrer ?

Cliquez sur Commencer depuis l'accueil pour enregistrer votre journée.

📦

Créer une catégorie

Allez dans Groupes & Articles pour créer vos catégories.

💵

Enregistrer les ventes

Indiquez les montants vendus dans chaque catégorie.

🛒

Enregistrer les achats

Indiquez les montants dépensés pour acheter vos marchandises.

💸

Enregistrer les dépenses

Ajoutez vos propres catégories : loyer, transport, électricité, salaire, etc.

📊

Résultat hebdomadaire

Jossell additionne automatiquement les opérations de la semaine.

📅

Résultat mensuel

Jossell regroupe les résultats de tout le mois.

💾

Conservation des données

Vos données sont conservées localement dans le navigateur.
