JOSSELL – MA GESTION  |  Conçu par Joseph Monsemvula

1) VOIR L'APPLICATION : double-cliquez sur index.html (Commencer pour tester).

2) INSTALLATION (bouton Télécharger) : le dossier doit être EN LIGNE en HTTPS.
   Netlify : app.netlify.com/drop > glissez le dossier JOSSELL-MA-GESTION > envoyez le lien.
   Ouvrez ce lien dans Chrome (Android/PC) ou Safari (iPhone), pas dans WhatsApp/Facebook.

3) ADMINISTRATION (dans l'application) : Plus > 10 appuis rapides sur le logo JM > code secret.
   Générez le code d'activation du client (son téléphone + durée) et envoyez-le par WhatsApp.
   Changez "JOSSELL-CHANGE-MOI-2026" dans index.html avant la mise en ligne.
